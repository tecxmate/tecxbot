A bot template for multilingual LINE groups with billing from day one.

Group commands

Use `/set en tw ja`, `/status`, `/off`, and `/on` inside LINE. No separate admin dashboard is required for the first template version.

Translation workflow

Messages are translated into the configured group languages using OpenAI, while preserving names, numbers, links, and formatting.

Capped usage

Each tenant has a character budget. When the cap is reached, the bot stops translating and points the group to the pricing page.
